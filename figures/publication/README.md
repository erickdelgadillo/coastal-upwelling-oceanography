# Generated publication panels

This directory contains the individual PNG panels generated by the four
historical publication Live Scripts. The scripts were run interactively with
MATLAB R2026a on 13 September 2026 using MATLAB's light figure theme.

## Inventory

| Directory | Live scripts | Contents | Files |
| --- | --- | --- | ---: |
| `supplementary_figure_1_ctd/` | `station3_ctd.mlx`, `station6_ctd.mlx` | Temperature, salinity, fluorescence, turbidity, and PAR for three seasons at two stations | 30 |
| `supplementary_figure_2_nutrients/` | `station3_nutrients.mlx`, `station6_nutrients.mlx` | NO2, NO3, NH4, TIN, PO4, SiO2, and chlorophyll-a for three seasons at two stations | 42 |

File names encode season, station, and variable, for example
`Winter_S3_Temp.png` and `Summer_S6_PO4.png`. Station 3 is offshore and Station
6 is coastal. The three seasons are winter, spring, and summer.

The 72 files are exact copies of the outputs written to `data/temporal/` during
the run. Copy integrity was verified with SHA-256 hashes. The working copies in
`data/temporal/` remain ignored by Git so future runs do not create accidental
changes to the curated figure set.

These files are individual panels. The final composite layouts used for
Supplementary Figures 1 and 2 were assembled separately for publication and
are not reproduced by the retained Live Scripts.
